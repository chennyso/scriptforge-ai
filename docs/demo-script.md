# Demo 视频讲解稿

1. 打开 ScriptForge AI 工作台，说明它解决小说作者把章节改成剧本时结构拆分成本高的问题。
2. 上传或粘贴 `examples/public-domain-novel.md`，展示系统识别到 3 个以上章节。
3. 设置剧本类型为影视剧，改编风格选择强化冲突，场景数设置为 6。
4. 点击生成，展示故事蓝图、场景预览和右侧 YAML。
5. 说明 YAML 通过 Schema 校验，角色、地点、场景、对白都可被程序读取。
6. 选择 `SC001`，点击强化冲突或影视化，展示局部重写。
7. 点击导出 YAML，展示可交付文件。
8. 打开 `docs/yaml-schema.md`，说明 Schema 的设计原因。
